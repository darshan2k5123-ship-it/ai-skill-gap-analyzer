# AI Skill Gap Analyzer

## Overview
This project analyzes resumes using AI and detects missing skills for a target job role.

## Features
- Resume Upload
- Skill Detection
- ATS Score
- Resume Match
- AI Career Advice
- Resume Review
- Cover Letter Generation
- Interview Questions
- ATS Keywords
- Project Recommendations
- PDF Report Generation

## Technologies
- Python
- Streamlit
- Google Gemini AI
- PDFPlumber
- ReportLab
- Matplotlib

## Run

pip install -r requirements.txt

streamlit run app.py
